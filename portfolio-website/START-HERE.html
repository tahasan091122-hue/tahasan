2 Your Admin Panel

Two ways in

  • Any page of the website → footer → Get in Touch → Admin Panel button
  • Or straight to your-site.netlify.app/admin/
Usernameadmin PasswordChangeMe123!
Everyone who has these files knows this password, so the panel will not save anything until you replace it. On your first sign-in it takes you straight to Admin Account — set your own password there and the rest unlocks. Your new password is stored only as a one-way hash and cannot be read back by anyone.

3 What you can change
  • Home Page — hero text, your photo, rotating job titles, stats, every section heading, tools list
  • My Work — add a client screenshot, a title and a short description; add or remove as many as you like
  • About Me — your photo and your story
  • Services — these also fill the home page cards, the footer and the Contact form dropdown
  • Testimonials — replace the sample reviews with real client ones
  • Contact Information — email, phone, WhatsApp, social links
  • Inbox — every message sent through the contact form
  • Images / Media — upload once, use anywhere
  • Theme / Colors — four colours change every accent; six ready palettes
  • Website Settings — brand name, logo image, browser tab icon, footer text, full content reset
  • Admin Account — username and password

Press Save and it is live. Every button writes to the server — nothing is pretend.

If a change does not show on the website within a few seconds, refresh once with Ctrl + Shift + R. The storage can take a moment to catch up.
4 Putting it online (already done once)

Kept here in case you ever start a fresh site.

এটা একবার করাই আছে। নতুন করে সাইট বানালে তখন লাগবে।

  1. Create a free account at github.com/signup
  2. github.com/new → name it my-portfolio, choose Private → Create repository
  3. Click uploading an existing file → open the website folder → select everything inside it (Ctrl + A) → drag into the browser → Commit changes
  4. In Netlify: Add new site → Import an existing project → GitHub → pick the repository → change nothing → Deploy
  5. On the project page click Make public, and rename the site under Project configuration → Change site name
Dragging the folder straight onto Netlify puts the pages online but leaves the Admin Panel dead — Netlify only switches the saving part on when the files arrive from GitHub. That is why step 3 exists.
5 Changing the site later

Day-to-day text, images, projects, reviews and colours — all of that is the Admin Panel. You never touch these files for that.

Only if the design or code itself changes do you re-upload: GitHub → your repository → Add file → Upload files → drop the new files → Commit changes. Netlify redeploys on its own in about a minute.

Re-uploading never wipes what you saved in the Admin Panel — your content and images live separately from the code.

Everything here has been tested end to end: login, saving, images, inbox, theme and password change.
